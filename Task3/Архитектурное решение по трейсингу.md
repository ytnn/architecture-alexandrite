# Архитектурное решение по трейсингу

## 0. Анализ системы компании и C4-диаграммы в контексте планирования трейсинга

В данный момент источником проблем является система MES и ее иртеграции с другими подсистемами: CRM API, MES API, RabbitMQ. Добавив трейсинг, можно увидеть проблемы с жизненным циклом заказа.

В трейсинг должны попадать:

- trace_id и span_id — для сквозной трассировки запроса

- instance_id, service_id - для определения в каком сервисе произошло событие 

- endpoint_URL — какой метод API вызывался

- duration/start_time

- специфические данные запроса

## 1. Мотивация

Распределённая архитектура приложения вносит сложность поиска ошибок. В данный момент невозможно понять происходит ли потеря сообщений или долгие расчёты заказа. Задержки в выполнении заказа приводят к поетере клиентов, отменам заказов и в конечном счете потери прибыли. Для эффективного выявления проблем необходимо внедрить трейсинг в критические места системы. Это ускорит поиск и исправление ошибок, повысит устойчивость работы системы, скорость обработки заказов и позволит сохранить клиентов, а так же привлечь новых и улучшить их лояльность.

## 2. Предлагаемое решение
Использовать OpenTelemetry + Jaeger для хранения и отоображения трассировок. Внедрить OpenTelemetry SDK и настроить сигналы трассирования для подсистем MES и ее интеграции с другими подсистемами: CRM API, MES API, RabbitMQ.

## 3. Компромиссы
1. Дополнительные расходы на оперативную память, место БД, CPU, сетевой трафик из-за большого объема строковых трейсов. Необходимо тщательно выбирать какие системы добавлять в трейсинг и следить за объемом данных и временем их хранения из-за расходов на облачную инфраструктуру
2. Сложность внедрения трейсов при интеграции со сторонними проприетарными системами
3. Конфиденциальные данные могут случайно попасть в трейсы


## 4. Аспекты безопасности
1. Внедрение аутентификации — зайти в систему смогут только сотрудники компании с актуальной учетной записью и ролью “Поддержка” из внутренней сети компании
2. Для удаленного доступа к трейсам должен использоваться VPN
3. Внедрить механизмы контроля и предотвращения логирования конфиденциальных данных
